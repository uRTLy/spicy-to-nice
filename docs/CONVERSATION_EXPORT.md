# Conversation Export

This repo includes sanitized conversation data and an in-app transcript page so reviewers can see how the project was planned and built with Codex.

## Files

- `scripts/export-codex-conversation.mjs`: reads a Codex JSONL session and exports visible user/assistant messages only.
- `public/transcript/conversation.json`: sanitized exported messages and attachment metadata used by the React route.
- `public/transcript/media/`: exported screenshots referenced by visible messages.
- `public/transcript/index.html`: static fallback viewer generated by the script.
- `src/ConversationPage.tsx`: primary in-app viewer.

```text
~/.codex/sessions/2026/05/18/rollout-2026-05-18T15-14-20-019e3b39-220f-7882-a4a8-dbb908a0ce24.jsonl
```

In the running app, the viewer is available at:

```text
/conversation/
```

The exporter intentionally skips:

- system/developer instructions
- hidden reasoning
- tool calls and tool outputs
- raw command output
- raw image data in JSON; visible screenshots are exported as separate media files

It also redacts common API key/token patterns and local `/Users/patrick` paths. Screenshot files are exported as-is, so visually inspect them before sharing outside the demo context.

## Regenerate

```bash
npm run export:conversation
```

To use a different Codex JSONL file:

```bash
node scripts/export-codex-conversation.mjs \
  --input /path/to/rollout.jsonl \
  --out-dir public/transcript
```

## Safety Checklist Before Commit

Run these before publishing an export:

```bash
rg "sk-|OPENAI_API_KEY|Authorization: Bearer|ghp_|github_pat_|npm_|pypi-|BEGIN PRIVATE KEY|/Users/patrick" public/transcript
npm run build
```

If available, also run a secret scanner such as `gitleaks` or `trufflehog`.

## Existing Tools Considered

- [`chat2html`](https://github.com/chezou/chat2html): supports Codex CLI JSONL and can generate a single HTML file. This is a good richer alternative, but we keep a small local exporter for deterministic redaction and to avoid publishing tool output by accident.
- [`codex-transcripts`](https://github.com/timvw/codex-transcripts): can render Codex transcripts and is useful for multi-page publishing.
- [`codlogs`](https://github.com/tobitege/codlogs): local Codex log browser/exporter with options to hide tool calls/results.

For this repo, the safest default is the local exporter because it includes only visible user/assistant messages.
